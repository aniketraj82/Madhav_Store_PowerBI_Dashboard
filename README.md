# Madhav E-Commerce Sales Dashboard

This project presents a Power BI sales dashboard for analyzing e-commerce performance across sales, profit, quantity, customers, product categories, payment modes, and regions.

## Business Problem

E-commerce businesses generate high volumes of sales data, but raw tables make it difficult to quickly identify profitable categories, loss-making periods, regional performance, and customer purchasing patterns. This dashboard converts sales data into a decision-ready view.

## Tools Used

- Power BI for dashboard creation and visualization
- Power Query for data cleaning and transformation
- DAX for calculated measures and KPIs
- Interactive filters and slicers for dynamic analysis

## Key Insights Covered

- Overall sales, profit, quantity, and average order value
- Monthly profit and loss trends
- Top-performing states and customers
- Sales distribution by product category and sub-category
- Customer payment mode preferences
- Quarter-wise and category-wise filtering

## Business Use Case

This dashboard can help business owners, sales managers, and analysts monitor performance, identify growth opportunities, and optimize sales strategy.
